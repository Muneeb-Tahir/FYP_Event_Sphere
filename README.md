## 📖 Overview

**Event Sphere** is a university event management application developed as a Final Year Project using Flutter and Supabase.

The goal of this project is to provide a single platform where students can discover events, register, receive notifications, and where society presidents and admins can manage events easily.

It brings students, society presidents, and administrators together through a centralized platform designed to simplify university event management.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- A Supabase project
- A Firebase project (for push notifications)

### 1. Clone the Repository

```bash
git clone https://github.com/Muneeb-Tahir/FYP.git
cd FYP
```

### 2. Configure Supabase

1. Create a project on the [Supabase Dashboard](https://supabase.com/dashboard).
2. Configure your database.
3. Set up the required authentication and storage services.
4. Configure your application with the Supabase project credentials.

### 3. Configure Firebase

1. Create a project on the [Firebase Console](https://console.firebase.google.com/).
2. Configure Firebase for your target platform.
3. Add the required Firebase configuration files.

### 4. Install Dependencies

```bash
flutter pub get
```

### 5. Run the Application

```bash
flutter run
```
