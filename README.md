# Event Sphere

A university event management application built as my Final Year Project using Flutter and Supabase.

The goal of this project is to provide a single platform where students can discover events, register, receive notifications, and where society presidents and admins can manage events easily.

---

## Features

- User authentication
- Create, edit and delete events
- Event approval system
- Register for events
- QR code attendance
- Society management
- Push notifications
- AI chatbot for basic assistance
- Bookmarks
- Dark and Light theme
- Offline support
- Reports and analytics

---

## Tech Stack

- Flutter
- Dart
- Supabase
- PostgreSQL
- Firebase Cloud Messaging
- Riverpod
- Hive
- FL Chart

## Getting Started

Clone the repository

```bash
git clone https://github.com/Muneeb-Tahir/Event-Sphere.git
```

Install packages

```bash
flutter pub get
```

Run the application

```bash
flutter run
```
